# Hospital_data_Analysis
End-to-end hospital analytics project — 6-table MySQL database, 8 SQL queries and a 3-page Power BI dashboard analysing revenue, admissions, recovery rates and billing across a simulated 500-bed Indian hospital.

Built a complete healthcare analytics system simulating a Data Analyst role at a 500-bed multi-specialty Indian hospital. Designed and populated a 6-table relational database in MySQL (14,000+ rows) covering patients, doctors, departments, admissions, billing and appointments. Wrote 8 analytical SQL queries using JOINs, CTEs, Window Functions and conditional aggregation to answer key business questions around revenue, doctor workload, length of stay, recovery rates and appointment no-shows. Connected MySQL live to Power BI and built a 3-page interactive dashboard — Overview, Admission Analysis and Financial Analysis — with 8 DAX-driven KPI cards, 10 charts and slicers. Key findings: ₹54.97M gross revenue, 75.8% recovery rate, 902 outstanding bills worth significant unrealised revenue, and ₹5.44L lost to 390 appointment no-shows.
